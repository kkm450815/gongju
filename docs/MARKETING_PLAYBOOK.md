# 마케팅 플레이북 (UTM·인플루언서 운영)

이 문서는 **개별 인플루언서·캠페인 단위로 성과를 분리 측정**하면서, 사람의 손이 가장 적게 가도록 운영하는 표준 절차를 정리합니다.

---

## 1. UTM 명명 규칙 (절대 어기지 말 것)

| 파라미터 | 형식 | 예시 | 메모 |
|---|---|---|---|
| `utm_source` | 플랫폼 소문자 | `youtube`, `twitter`, `instagram`, `tiktok`, `blog`, `newsletter`, `discord`, `reddit` | 사람이 아니라 채널 |
| `utm_medium` | 매체 분류 | `video`, `social`, `email`, `cpc`, `cpm`, `organic`, `referral` | 광고 vs 자연 유입 구분 |
| `utm_campaign` | 캠페인 코드 | `launch_2026q2`, `halloween_2026`, `kickstarter_prelaunch` | 시즌·이벤트 단위 |
| `utm_content` | 인플루언서/소재 ID | `creator_001`, `banner_a`, `banner_b` | A/B는 여기서 |
| `utm_term` | 키워드(선택) | `korean_god_game` | SEO·SEM 키워드만 |

**규칙**:
- 모두 소문자, 공백 금지(`_`로 연결)
- 한글 금지 (인코딩 깨짐 위험)
- 한 번 정한 값은 재사용 — 매번 새 이름을 만들면 분석이 망가진다

## 2. 짧은 코드 체계

`<언어>-<플랫폼2자>-<일련번호3자>`

| 언어 | 플랫폼 | 예시 |
|---|---|---|
| KO | YT(YouTube), TW(Twitter), IG(Instagram), TT(TikTok), BL(Blog), NL(Newsletter) | `KO-YT-001` |
| EN | 동일 | `EN-TT-014` |
| JA | 동일 | `JA-YT-003` |
| ZH | 동일 | `ZH-IG-007` |

이 짧은 코드를 단축 URL의 마지막 토큰으로 사용:
```
gongju.game/r/KO-YT-001
```
→ 302 → `gongju.game/?utm_source=youtube&utm_medium=video&utm_campaign=launch_2026q2&utm_content=creator_001&ref=KO-YT-001`

## 3. 인플루언서 콜드메일 → 컨텐츠 → 정산 흐름

```
[1] 후보 발굴 (수동/Notion)
    └─> 채널 URL, 평균 조회수, 컨택 가능 여부 정리
[2] 콜드메일 발송 (템플릿 § 4)
[3] 응답 → 협업 확정
[4] 관리자 페이지 /admin/creators 에서 'creators' 행 추가
    └─> 자동 발급된 short_code(예: KO-YT-001) 전달
[5] 인플루언서가 영상/포스트 게시
[6] 매주 월요일 09:00 KST → /admin/creators 표 검토
[7] 월말 정산 — utm_content 기준 다운로드/매출에 비례한 보상
```

## 7. 자주 하는 실수

1. **인플루언서마다 utm_campaign을 새로 만든다** → 캠페인은 시즌으로, 인플루언서는 utm_content로.
2. **단축 URL 없이 풀 URL을 그대로 영상 설명란에 붙인다** → 클릭 카운트가 누락된다.
3. **이메일/SNS 링크에 `utm_*` 안 붙인다** → 자연 유입과 구분 못 함.
4. **GA·PostHog·Supabase 3중 측정에서 어느 것이 진실인지 정하지 않는다** → 본 운영에서는 **Supabase `visits`/`downloads`를 진실 데이터**로 두고, PostHog는 사용자 행동·펀널만.
